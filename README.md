# Менеджер задач PWA

Итоговый проект по практическим занятиям 13–18 по дисциплине «Фронтенд и бэкенд разработка».

Приложение реализует:
- офлайн-режим через `Service Worker`;
- установку как PWA через `Web App Manifest`;
- App Shell с динамической подгрузкой контента;
- синхронизацию заметок между клиентами через `Socket.IO`;
- push-уведомления и напоминания с действием «Отложить на 5 минут».

## Что реализовано по практикам

### Практика 13. Service Worker
- регистрация `Service Worker` на клиенте;
- кэширование оболочки приложения, HTML-фрагментов, JS, CSS, манифеста и иконок;
- работа приложения офлайн для уже посещённых ресурсов.

### Практика 14. Web App Manifest
- файл `manifest.json` с `name`, `short_name`, `start_url`, `display`, `background_color`, `theme_color`, `description`, `icons`, `scope`;
- подключение манифеста и мобильных meta-тегов в `index.html`;
- набор иконок для установки приложения.

### Практика 15. App Shell
- постоянная оболочка интерфейса в `index.html`;
- загрузка страниц `content/home.html` и `content/about.html` через `fetch`;
- локальный файл `styles.css`, чтобы интерфейс не зависел от внешнего CDN в офлайн-режиме.

### Практика 16. WebSocket + Push
- сервер на `Express` + `Socket.IO`;
- синхронизация новых заметок между клиентами событием `noteCreated`;
- подписка и отписка от push-уведомлений;
- отправка push-уведомлений при создании обычной заметки.

### Практика 17. Напоминания
- форма создания заметки с датой и временем напоминания;
- планирование напоминания на сервере через `setTimeout`;
- уведомление с кнопкой «Отложить на 5 минут»;
- обработка `notificationclick` в `sw.js`.

### Практика 18. Подготовка к контрольной работе №3
- приложение приведено в рабочее состояние;
- `README.md` описывает реальную реализацию;
- добавлен скрипт проверки синтаксиса.

## Запуск проекта

### 1. Установка зависимостей

```bash
npm install
```

### 2. Запуск сервера

```bash
npm start
```

Сервер запускается по адресу:

```text
http://localhost:3001
```

### 3. Проверка синтаксиса

```bash
npm run check
```

## Как пользоваться приложением

### Обычная заметка
1. Откройте вкладку «Главная».
2. Введите текст заметки.
3. Нажмите «Добавить заметку».

### Напоминание
1. Заполните текст напоминания.
2. Выберите будущую дату и время.
3. Нажмите «Добавить с напоминанием».

### Push-уведомления
1. Нажмите «Включить уведомления».
2. Разрешите уведомления в браузере.
3. После этого сервер сможет отправлять push-сообщения.

## Важное замечание

Для push-уведомлений и корректной работы PWA лучше использовать `localhost` или HTTPS. Для локальной проверки `localhost` подходит, потому что браузеры считают его безопасным контекстом для `Service Worker` и `Push API`.
