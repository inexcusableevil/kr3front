# PWA Приложение «Заметки»

Методические указания к практическим занятиям 13–18 по дисциплине **«Фронтенд и бэкенд разработка»**.

---

## О проекте

Приложение для заметок с поддержкой офлайн-режима, push-уведомлений и напоминаний. Реализует ключевые технологии Progressive Web App (PWA) и демонстрирует работу с сервис-воркерами, WebSocket, Push API и кэшированием.

---

## Практические занятия 13–18

### Практика 13 — Основы PWA. Web App Manifest
- Создание Web App Manifest (`manifest.json`)
- Настройка иконок для различных размеров экрана
- Добавление мета-тегов для мобильных устройств
- Настройка `theme-color`, `display`, `orientation`

### Практика 14 — Service Worker. Кэширование и офлайн-режим
- Регистрация и жизненный цикл Service Worker (`sw.js`)
- Стратегии кэширования: **Cache First** для статики, **Network First** для динамического контента
- Управление версиями кэша и очистка устаревших версий
- Обеспечение работы приложения без подключения к сети

### Практика 15 — Push-уведомления
- Подписка на push-уведомления через Push API
- Интеграция с VAPID (Voluntary Application Server Identification)
- Отображение уведомлений через `self.registration.showNotification()`
- Обработка кликов по уведомлениям (`notificationclick`)

### Практика 16 — WebSocket. Синхронизация в реальном времени
- Настройка сервера Socket.IO (`server.js`)
- События `newTask` / `taskAdded` для синхронизации между клиентами
- Отображение уведомлений о новых задачах от других клиентов
- Обработка подключений и отключений клиентов

### Практика 17 — Напоминания и отложенные уведомления
- Создание заметок с напоминанием на определённую дату/время
- Серверное хранение таймеров напоминаний (`Map`)
- Отправка push-уведомлений по срабатыванию таймера
- Кнопка **«Отложить на 5 минут»** в уведомлении (эндпоинт `/snooze`)

### Практика 18 — Подготовка к контрольной работе №3
- Тестирование работоспособности приложения
- Подготовка документации (данного README.md)
- Проверка доступности репозитория

## Технологии

| Технология | Назначение |
|---|---|
| **Service Worker** | Кэширование, офлайн-режим, обработка push |
| **Web App Manifest** | Установка приложения на устройство |
| **Push API** | Push-уведомления |
| **WebSocket (Socket.IO)** | Синхронизация данных в реальном времени |
| **localStorage** | Локальное хранение заметок |
| **Express.js** | HTTP-сервер для раздачи статики и API |
| **web-push** | Отправка push-уведомлений с сервера |

## Установка и запуск

### 1. Установка зависимостей

```bash
npm install
```

### 2. Запуск сервера

```bash
npm start
```

Сервер запустится на **http://localhost:3001**

### 3. Открытие приложения

Откройте браузер и перейдите по адресу **http://localhost:3001**

## Функциональность

### Создание заметок
- Введите текст заметки и нажмите **«Добавить»**
- Заметки сохраняются в `localStorage`

### Создание напоминаний
- Введите текст напоминания и выберите дату/время
- Нажмите **«Добавить с напоминанием»**
- Push-уведомление будет отправлено в указанное время

### Push-уведомления
- Нажмите **«Включить уведомления»** для подписки
- Нажмите **«Отключить уведомления»** для отписки
- При получении уведомления о напоминании доступна кнопка **«Отложить на 5 минут»**

### Офлайн-режим
- Приложение работает без подключения к интернету
- Статические ресурсы загружаются из кэша
- Динамический контент загружается из кэша при отсутствии сети

### Синхронизация
- При открытии приложения в нескольких вкладках новые заметки синхронизируются через WebSocket

## Ключевые особенности реализации

### Service Worker: стратегии кэширования

| Ресурс | Стратегия |
|---|---|
| Статика (`/`, `/index.html`, `/app.js`, иконки) | **Cache First** |
| Динамический контент (`/content/*`) | **Network First** → fallback на кэш |

### Push-уведомления

- VAPID-ключи настроены для идентификации сервера
- Подписки хранятся на сервере в массиве `subscriptions`
- Уведомления отправляются всем подписанным клиентам

### Напоминания

- Таймеры хранятся в `Map` на сервере
- При срабатывании таймера отправляется push-уведомление
- Эндпоинт `/snooze` позволяет отложить напоминание на 5 минут
